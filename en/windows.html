Open PowerShell (no admin rights needed) and run:


irm https://lomosw.lomorage.com/windows/install.ps1 | iex

This installs "Lomorage" to your user profile and starts it automatically -- no installer window, no reboot. A "Lomorage" icon appears in your Start menu and system tray; open it from either any time. It checks for and installs updates automatically once a day.

See the full install guide for details -- choosing a custom data folder, accessing it from your phone, uninstalling, and more.

Alternative: prefer a traditional installer with a GUI setup wizard instead? Download the MSI installer.
